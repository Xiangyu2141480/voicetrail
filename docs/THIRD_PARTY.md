# Third-party sources and licenses / 第三方来源与许可

Original VoiceTrail code/documentation is MIT. That license does not cover third-party notices, dependencies, weights or data. This release distributes source/configuration/documentation and license texts only: no dependency wheels, `node_modules`, built application bundles, FFmpeg binaries, model weights or audio.

Transitive licenses include MIT, BSD, ISC, Apache-2.0, PSF-2.0, MPL-2.0 (certifi and part of tqdm), CC BY 4.0 (caniuse-lite), and bundled licenses in numerical/PyTorch wheels. SoundFile's wheel includes `_soundfile_data/COPYING` (LGPL-2.1) for libsndfile; this is separate from its Python wrapper. NumPy/SciPy/PyTorch notices include additional libraries and must not be flattened to the primary package license.

The installed metadata and actual license texts are the primary verification sources here; public package URLs provide traceability. Optional uninstalled npm platform wheels use locked npm license metadata; the Windows-only colorama entry uses upstream PyPI metadata. CPU-index configuration follows [uv's official PyTorch integration guide](https://docs.astral.sh/uv/guides/integration/pytorch/).

If dependency binaries, browser binaries, weights, audio or a prebuilt app are distributed in a future release, their redistribution/attribution/source/NOTICE obligations must be evaluated for the exact artifacts. This source-only inventory is not approval of a future bundled installer.
